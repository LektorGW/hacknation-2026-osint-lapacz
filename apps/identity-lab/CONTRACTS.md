# Kontrakty laboratorium

Node.js 22+, ES modules, no third-party dependencies. All identifiers and people are synthetic; email domains end in `.test`. The application runs on loopback. Do not import external user data or call real social networks.

## Generator (lib/generator.mjs, lib/services.mjs)

Export `generateDataset({seed = 67, people = 180} = {})` returning `{publicData, groundTruth}`. Export `SERVICES` from services.mjs: 27 entries `{id, slug, name, category, description, color}` with category `social` (5), `marketplace` (7), `forum` (15). publicData: `{meta:{seed, generatedAt, people, ...}, services, accounts, posts, listings, threads}`. IDs are stable strings. Account: `{id, serviceId, username, displayName, email, bio, location, avatarColor, joinedAt, interests:[], activeHours:[], walletAddresses:[], ...}`. Posts: `{id, accountId, serviceId, text, createdAt, likes}`. Listing: `{id, accountId, serviceId, title, description, price, currency:'PLN', createdAt, category}`. Thread: `{id, accountId, serviceId, title, text, createdAt, replies:[{id, accountId, text, createdAt}]}`. No `personId`, `personaId`, true `role` or linking truth in publicData. Truth: `{people:[{id, ...}], accountLinks:[{accountId, personId, role}], scenarios:[...]}`; roles `ordinary`, `multi`, `fake`. Include hard negatives (same username on unrelated people), varied emails/aliases and deceptive profiles. Public similarity is imperfect. Seed deterministic, stable generatedAt. Wallet addresses can be deterministic test strings prefixed `lab1` with hex suffix, never real-chain keys. Generator owns generator tests.

## Identity (lib/identity.mjs)

Export `compareAccounts(a,b,context?)` -> `{probability, score, evidence:[{signal, label, weight, detail}], caveats:[]}`. Never use ground truth or hidden IDs in scoring. `resolveIdentity(query,accounts,{limit=40}={})` -> `{query, anchors:[account IDs], matches:[{account, probability, score, evidence, via?, caveats}], caveats:[]}`. Query exact/partial email, username, displayName, account ID, wallet; exact matches anchors, partial matches search seeds with lower certainty. Independent weak evidence must not become certainty; ubiquitous usernames downweighted; no certainty from same display name. Export `evaluateIdentity(accounts,groundTruth,{threshold=0.75,maxPairs=20000}={})` -> metrics object (precision/recall/f1 plus confusion counts, sample method, examples). Pair sampling deterministic and avoid default all-negative sampling. Truth used in evaluation only. Calibration limitations explicit. Identity agent owns identity tests and documentation IDENTITY.md.

## Blockchain (lib/blockchain.mjs)

Export `createBlockchain({seed=67,walletCount=24,difficulty=2}={})` returning a JSON-serializable chain state (includes private test keys ONLY in local data state; public API strips these). Export `publicBlockchain(state)` with safe wallets `{id,address,label,balance,...}` no private keys; blocks, mempool and summary. Export `submitTransfer(state,{from,to,amount,fee=1})`, `mineBlock(state,{minerAddress}={})`, `validateBlockchain(state)` with `{valid,errors,...}`, `simulateReorg(state,{depth=1}={})`. Operations mutate state, return result or throw descriptive errors. Integer units token LAB; ECDSA/Ed25519 signatures validated; UTXO double spend rejection, fees/coinbase reward, block hashes, configurable inexpensive PoW and competing branch simulation with actual cumulative-work selection. Seeded synthetic initial transfers. Account-address links use generator-compatible `lab1` derivation or root will add public wallet links after generation. Agent owns blockchain tests and BLOCKCHAIN.md. No claims of real network consensus or monetary value.

## Root / server

Root owns package.json, server.mjs, public/, README.md, integration tests, launcher scripts. API `/api/status`, `/api/services`, `/api/accounts`, `/api/search`, `/api/resolve` (POST query), `/api/evaluate` (POST threshold), `/api/ground-truth` (explicit benchmark only), `/api/blockchain`, POST `/api/blockchain/transfer`, `/mine`, `/reorg`, GET `/validate`, POST `/api/regenerate`, exports. All local, no external APIs. Normal responses exclude ground truth and private keys. Portals at `/s/:slug` plus optional 27 listeners on 8801..8827. Public account details `/api/accounts/:id` and UI `/s/:slug/profile/:id`.
